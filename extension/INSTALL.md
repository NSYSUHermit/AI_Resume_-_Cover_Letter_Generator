# 安裝說明

> 這份是給拿到 zip 檔、要自己手動安裝的人看的。
> 如果你拿到的是 Chrome 線上應用程式商店的連結，直接點「加到 Chrome」就好，不用看這份。

## 安裝（約 2 分鐘）

### 1. 解壓縮到一個「不會被你刪掉」的地方

Chrome 是直接讀取這個資料夾的路徑，**不是把檔案複製走**。所以之後只要你搬動或
刪除它，擴充功能就會壞掉。

建議放在家目錄下，例如：

- macOS：`~/Applications/ai-resume-sidepanel/`
- Windows：`C:\Users\你的名字\ai-resume-sidepanel\`

**不要**放在「下載」資料夾——很多人會定期清空那裡。

### 2. 開啟擴充功能頁面

網址列輸入：

```
chrome://extensions
```

### 3. 打開右上角的「開發人員模式」

### 4. 點左上角「載入未封裝項目」，選你剛才解壓縮出來的資料夾

**選資料夾本身，不要進去選 `manifest.json`。** 資料夾裡應該直接看得到
`manifest.json`、`background.js`、`icons/` 這些東西。

### 5. 把它釘到工具列

點網址列右邊的拼圖圖示 → 找到「AI Resume Builder 側邊欄」→ 點旁邊的圖釘。

裝好了。點那個藍色的「AR」圖示就會打開側邊欄。

---

## 第一次使用

1. 側邊欄第一次開啟會**空白數十秒**——網站主機是免費方案，會休眠，要等它醒來。
   不是壞掉，等一下就好。
2. 在側邊欄裡註冊 / 登入。
3. 貼上你自己的 Google Gemini API 金鑰（免費申請：<https://aistudio.google.com/apikey>）。
   AI 功能跑在你自己的金鑰上。
4. 切到 **Generator**。
5. 開一個職缺頁，按側邊欄頂端的「**抓取這頁的 JD**」。

第一次按抓取按鈕時，Chrome 會問你要不要授予讀取網頁的權限——**要按允許**，
不然抓不到職缺內容。（這個權限刻意設計成安裝時不授予，你按下按鈕的當下才問。）

---

## 幾件要有心理準備的事

**每次開 Chrome 會跳提示。** Chrome 對所有「開發人員模式」載入的擴充功能都會這樣
提醒，關掉那個提示就好，擴充功能照常運作。這是手動安裝的必然代價，只有從商店安裝
才不會有。

**不會自動更新。** 有新版本的時候，你要重新下載、解壓縮蓋掉舊資料夾，然後回到
`chrome://extensions` 點那張卡片上的 ↻ 重新載入。

**抓取後如果跳出「已複製到剪貼簿」**，不是壞掉——那是備援路徑。按 `Cmd+V`（Windows
是 `Ctrl+V`）貼到 Job description 欄位即可。

---

## 隱私

這個擴充功能不儲存任何東西，沒有分析追蹤，也沒有自己的伺服器。只有在你按下抓取
按鈕的當下才會讀取網頁，讀到的文字只會進到履歷產生器，不會送到別的地方。

完整說明見 [`PRIVACY.md`](PRIVACY.md)，原始碼也是公開的。

## 移除

`chrome://extensions` 找到它，按「移除」。然後把解壓縮出來的資料夾刪掉就乾淨了。
